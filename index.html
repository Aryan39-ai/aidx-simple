Open projects

Work a student could pick up now. Each one is a question we are trying to answer.

Can an agent be trusted with real tools?

Honours or summer intern · S. Aryan

Give an agent a small set of real tools and a budget, then log every step to see where it goes wrong when nobody is checking.

You would build the sandbox and compare how two agents spend the same budget.

How far does a poisoned input travel?

Honours or PhD · A. Arjun

One bad input goes into a chain of agents that trust each other. We measure how many steps it survives, and what stops it.

You would write the test cases and turn the results into a dataset.

Does an explanation change the decision?

Honours · S. Aryan

People make the same decision with and without an AI explanation. We look at whether the explanation changes the choice, or only their confidence in it.

You would run the sessions and analyse the results.
